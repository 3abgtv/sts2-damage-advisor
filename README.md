# 伤害顾问 / Damage Advisor

《杀戮尖塔 2》的**只读战斗顾问**：战斗中在屏幕上给出一块面板，告诉你**这一回合该怎么出牌**。

- 🛡 **保命优先**：先算敌人本回合的来袭伤害，在"不死 / 少掉血"的前提下再追求最大输出
- 🎯 **怪物编号**：多怪时按屏幕顺序编号 1/2/3，推荐里直接写"打几号"
- 💀 **斩杀提示**：能不能斩杀、差多少、"中毒先手击杀（它本回合不会出手）"
- 🌿 **猎人机制**：中毒、小刀、弃牌、抽牌、能量、敏捷、易伤、力量削减、X 费、子弹时间等
- 🔒 **只读**：不自动出牌、不发送动作、不修改战斗状态 → 单人与联机都能用

> 它**不会替你操作**，只给建议。所有判断都基于当前真实战斗状态与你自己的手牌。

## 安装

**方式一：Steam 创意工坊**（推荐，自动更新）

在创意工坊订阅本 Mod 即可，无需手动放文件。

**方式二：手动安装**

1. 把 `DamageAdvisor.dll` 和 `DamageAdvisor.json` 放进：

   ```
   <游戏目录>/mods/DamageAdvisor/
   ```

2. 启动游戏（**必须通过 Steam 启动**），在载入 Mod 的确认框里同意即可。
3. 进入战斗，面板出现在左上角。

不需要任何前置 Mod（不依赖 RitsuLib）。

> ⚠️ **两个渠道的产物不同**：GitHub Release 里是**开发版**（含 `F9` 注入测试牌，方便调试）；
> 创意工坊版**编译期就剔除了** `F9` 注入与卡池转储，因此工坊版的 `affects_gameplay: false` 名副其实。
> 工坊版的面板标题与日志里版本号带 `-ws` 后缀（如 `v0.9.8-ws`），一眼可辨。

## 按键

| 按键 | 作用 |
|---|---|
| `F6` | 切换优先级模式：**保命优先** ⇄ **输出优先** |
| `F7` | 循环"允许掉血上限"：0 → 1 → 2 → 3 → 5（0 = 严格保命，不受伤） |
| `F8` | 显示 / 隐藏面板 |
| `F10` | 折叠 / 展开（折叠后只留推荐与斩杀两行） |
| 鼠标拖动 | 把面板拖到你喜欢的位置 |
| `F9` | **仅开发版**：往手牌注入一张测试牌（不会污染卡组，战斗结束即消失）。创意工坊版没有这个功能 |

## 配置

首次运行会在 `mods/DamageAdvisor/DamageAdvisor.cfg` 生成：

```ini
# 愿意承受的掉血上限，0 = 严格保命（无伤优先）
hpLossBudget=0
collapsed=False
```

改完直接生效（`F7`/`F10` 也会写回这里）。

## 推荐逻辑

**保命优先（默认）**：

```
不死  →  掉血 ≤ 预算（超预算则先比谁掉血少）  →  优先击杀  →  最大伤害
```

**输出优先（F6 切换）**：

```
不死  →  优先击杀  →  最大伤害  →  掉血最少
```

输出优先只保证"不致死"，可能让你挨打换输出；模式与掉血上限都记在 `DamageAdvisor.cfg` 里。

- **优先击杀**是跨回合考量：打死一只怪 = 本回合它的来袭归零 + 省掉它下一轮的攻击。
- 敌人意图伤害用游戏自己的 `AttackIntent.GetSingleDamage × Repeats`；卡牌伤害用游戏自己维护的卡面预览值（已含力量 / 虚弱 / 易伤等修正）。
- 搜索是有限状态机上的 DFS（含目标选择、X 费、弃牌分支），并对同名卡去重，通常只需几十到几千个节点。

## 联机（多人模式）

**可以直接用，但要知道边界：**

- ✅ **不会干扰联机**：本 Mod 是纯只读的——不执行动作、不发网络包、不改战斗状态，因此不会造成不同步。
- ✅ **来袭伤害是准的**：联机下敌人攻击对**全队造成相同伤害**，所以按"我自己"作为目标计算就是准确值；而格挡/血量本来就是个人数据，模型用的正是你自己的。
- ❌ **不考虑队友**：队友的输出、中毒、易伤、以及"队友先把怪打死了"都不参与计算——所以如果队友会先解决掉某只怪，你的"预计掉血"会偏保守。
- ⛔ **`F9` 注入测试牌在联机时被禁用**（会真实改动本地战斗状态、可能不同步）。单人时可用；**创意工坊版编译期就没有该功能**。
- ❓ **能否进房间取决于游戏的 Mod 一致性检查**：本项目声明 `affects_gameplay: false`（非玩法改动），通常比玩法 Mod 宽松，但请在多人房间里自行验证。

## 随状态变化的牌（顺序会影响收益）

这几张牌的收益取决于**出牌顺序**，模型在出牌时按当时的搜索状态实时计算，所以推荐会自动把它们排到最优位置：

| 牌 | 规则 | 推荐里通常出现在 |
|---|---|---|
| 终结技 `Finisher` | 本回合每打出过一张攻击牌（含自身）造成一次伤害 | **最后**（先铺垫攻击牌） |
| 飞镖 `Flechettes` | 手牌中每有一张技能牌造成一次伤害 | **最前**（先打掉技能牌会减少计数） |
| 蜃景 `Mirage` | 格挡 = 所有敌人中毒层数总和 | 上毒之后 |
| 铭记死亡 `MementoMori` | 本回合每弃一张牌 +4 伤害 | 弃牌之后 |

## 卡牌词条（keywords）

| 词条 | 是否影响本回合计算 |
|---|---|
| **奇巧 Sly** | ✅ **影响**：被丢弃时会**自动打出**该牌（不花能量）。已实现——弃牌时会优先弃奇巧牌，并按自动打出的效果结算（伤害/格挡/抽牌/能量/中毒等） |
| 不可打出 Unplayable | ✅ 影响：标记为不可打出，不参与推荐 |
| 消耗 Exhaust | ⚪ 不影响本回合（每张牌本回合只打一次） |
| 保留 Retain / 固有 Innate / 虚无 Ethereal | ⚪ 影响后续回合，本回合不参与计算 |

面板上每张手牌会显示词条，例如：`翻越撑击  1费  7伤/敌 [奇巧]`

## 已知限制

- 只算**你自己**：联机时敌人意图按"对全队"的总伤害计算，所以预计掉血偏保守。
- 只算**本回合**：抽牌按牌堆已知顺序模拟，但不预测下回合的抽牌与敌人换招。
- 未建模的牌会**明确标注原因**（例如刀刃陷阱、爆发、夜魇），不会给出自以为正确的建议。
- 弃牌是确定性策略（优先弃可触发牌，其次弃期望值最低的），没有对"弃哪张"做完整搜索。
- 小刀伤害 = 基础值 + 力量 + 精准；其它遗物/能力修正未全部覆盖。

## 构建

需要 .NET 9 SDK 和本机游戏程序集：

```powershell
# 开发版（含 F9 注入与卡池转储）→ 部署到 <游戏目录>/mods/DamageAdvisor/
pwsh -File build.ps1

# 创意工坊版（编译期剔除测试功能）→ 填充 workshop/content/ 并打印上传命令
pwsh -File build.ps1 -Workshop
```

两个产物都出自同一份源码，靠编译常量 `WORKSHOP` 区分（见 `DamageAdvisor.csproj`）。
脚本会**校验产物身份**：工坊版若检出注入/转储代码、或缺少 `<版本>-ws` 字符串就直接报错，
绝不让带测试功能的 DLL 进入 `workshop/content/`。

发版时记得同步两处版本号：`DamageAdvisor.json` 的 `version` 与 `src/Entry.cs` 的 `Version`
（工坊版的 `-ws` 由编译常量自动拼接，无需手写）。

## 实现笔记（踩过的坑）

- UI 必须挂到游戏根节点 `NGame.Instance`；挂 `SceneTree.Root` 的延迟调用会落空，节点进不了场景树。
- 动态加载的 Mod 程序集里，Godot 的 `_Ready` / `_Process` 虚函数**不会被派发**：UI 由入口显式构建，刷新用 `SceneTree.ProcessFrame` 信号驱动。
- 卡面效果按**变量类型**匹配（`BlockVar` / `PowerVar<PoisonPower>` / `CardsVar` / `RepeatVar`），不要猜键名。
- `ModelDb` 在 Mod 初始化时还没建好，卡池相关逻辑要延后到首次战斗。
